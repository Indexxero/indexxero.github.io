Verify an arr-check pack

An arr-check run writes receipt.json: the sha256 of every input, of pilot.py and of every output. This page recomputes each one from the files chosen here and says, file by file, whether it matches.

The files stay in this tab. This page is one file with nothing to load: no scripts from elsewhere, no fonts, no analytics. Once files are chosen it makes no network request of any kind. The hashes are computed by the browser's own Web Crypto. The browser's network panel shows it.

A match proves that these exact files are the ones the receipt names. It does not prove the method is right or that the inputs are true.

1. Choose the files

Files can be added in more than one go: the outputs first, then the schedule, the invoices, the mapping and any ledger, answers, payments or rates file the run used. pilot.py too, to check the code.
